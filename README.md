# WC4 S 评分计算器

世界征服者 4 集团军困难模式评分工具。支持实时评分、S 门槛差值、最低功勋目标、最晚通关回合，以及三套界面设计。

页面由纯 HTML、CSS、JavaScript 构成，可直接发布到 GitHub Pages。无需安装依赖。

## 使用

打开 `index.html`，或在本目录启动静态服务器 `python -m http.server 8765`。

输入通关回合、结算时城市数量、剩余功勋点、已消耗功勋点。页面预估困难模式获胜后的评分。

## 评分依据

本工具根据本次核对的安卓 1.30.0 APK 中的集团军结算实现制作。

- 回合分为 `floor(10000 × sqrt(100 / rounds))`。
- 城市分为 `cities × 100`。
- 功勋分为 `floor(400 × sqrt(merit) × (100 / rounds)^(1/4))`。
- 累计功勋点为 `已消耗功勋点 + floor(剩余功勋经验 / 100)`。
- 总分为三个分项相加，S 的最低总分为 **28,001**。

`score.js` 使用 `Math.fround` 近似原生单精度运算，分项分别截断取整。评级区间取自 `ConquerPrizeSettings.json` 的 `ArmyGroupMin / ArmyGroupMax`，原生算分函数地址为 `0x378700`。

本工具适用于上述版本的集团军困难模式，包括《遗失的钟声》困难图。其他模式或改版的实际结算可能不同。页面没有收集战局数据的后端。

## 界面

可在页面顶部切换「作战台」「数据卡」「仪表盘」。界面偏好保存在本机浏览器。战局分享通过 URL 参数完成。

## 部署

将 GitHub Pages 的发布来源设为 `Deploy from a branch`，选择 `main` 分支的根目录 `/ (root)`。
